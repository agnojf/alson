# Changelog

## 2.0.0 (2026-09-17)

- Renamed the package and bundled skeleton to ACTS Workflow Template.
- Replaced legacy terminology with workflow terminology and renamed the workflow configuration path.
- Renamed the package to `acts-workflow-template` and the bundled template path to `templates/workflow/`.

## 1.1.0 (2026-08-30)

- Added reusable Measure and Learn stage blueprints.
- Added an 80% default quality gate with acceptance-criteria enforcement.
- Added correction routing, blocked and paused run states, and resume guidance.
- Updated setup, validation, and portable workflow templates.

## 1.0.0 (2026-08-29)

- Initial portable release of the reusable workflow template.
- Workflow setup with destination confirmation and validation
- Five-layer context architecture and selective loading guidance
- Explicit composable stage contract guidance
- Bundled workflow skeleton, configuration templates, setup materials, and stage template
