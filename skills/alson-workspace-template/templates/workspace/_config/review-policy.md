# Review Policy

## Review Levels

| Level | Use when | Agent action |
|---|---|---|
| None | Low-risk reversible work | Continue and report result |
| Review | Human judgment materially affects downstream work | Stop and request review |
| Approval | Governance, commitment, release, or irreversible action | Stop and request explicit approval |

## Default Rule

If a downstream step would make an important decision harder or more expensive to reverse, require review before proceeding.
