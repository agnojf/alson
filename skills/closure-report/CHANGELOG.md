# Changelog

## 1.0.0 (2026-07-29)

- Initial portable release from `workspaces/closure-report`
- Build-Measure-Learn pipeline for producing audited Project Closure Reports
- Sections: Closure summary, Objectives and delivery status, Deliverables completed, Open items and handoff, Lessons learned, Administrative and contractual closure, Approvals
- Evidence-based analysis with source notation
- Mandatory acceptance criteria with pass/fail gates
- Diagnostic quality rubric (1-13 scoring, 8 dimensions)
- Repeat-run support: loads prior `what-now.md` when run folder already exists
- Status command: reports stage completion from output file presence
- Build handoff produced alongside report for traceability
