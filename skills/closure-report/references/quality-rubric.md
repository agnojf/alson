# Quality Rubric -- Project Closure Report

Use this rubric after the acceptance criteria pass/fail check to score overall quality.

## Score Scale

| Score | Meaning |
|---:|---|
| 1 | Unusable or missing |
| 2 | Major gaps |
| 3 | Basic but weak |
| 5 | Acceptable |
| 8 | Strong |
| 13 | Excellent / decision-ready |

## Criteria

| # | Criterion | What to Check |
|---|-----------|---|
| 1 | Closure completeness | Project name, closure scope, closure date, reason, and repository location are all documented |
| 2 | Delivery status | Final scope, schedule, cost, and quality status are summarized with planned vs actual |
| 3 | Deliverable acceptance | Final deliverables are listed with acceptance status, accepted by, and evidence references |
| 4 | Outstanding items | All outstanding items have owners and target actions. None is explicitly stated if empty |
| 5 | Handover and admin closure | Transition or handover status is documented. Financial, contractual, and repository closure are covered |
| 6 | Lessons quality | Key lessons are captured in actionable format (Start / Keep / Stop) |
| 7 | Approvals | Required approval roles are listed with name, signature, and date. Evidence gap is noted if unsigned |
| 8 | Conciseness | No filler paragraphs, repetition, or unnecessary sections. Document leads with the answer |

## Percentage Conversion

Quality % = (total awarded points / total possible points) x 100

Total possible points = number of criteria x 13

Passing threshold: 95%

A critical acceptance-criteria failure blocks passing regardless of rubric score.
