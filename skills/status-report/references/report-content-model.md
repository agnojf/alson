# Report Content Model

Every status report contains these sections. Sections with insufficient evidence are rendered with a Gray label and a clear "Insufficient data" note. Sections with no content are omitted.

The header sits above the section list. It displays the project name, report date, overall RAG and trend, and the next critical date and item.

---

## Sections

| # | Section | Content | Evidence Required | Format |
|---|---------|---------|-------------------|--------|
| 1 | Pulse | Overall RAG and trend, headline facts, next critical date and item | Cross-dimension evidence | Short paragraph and facts table |
| 2 | Key metrics | Current milestone completion, days to milestone target | Milestone and work-performance data | Two-row metrics table |
| 3 | Health dashboard | RAG per dimension (scope, schedule, cost, quality, risk, resources) with trend, confidence, primary metric, finding, and evidence citation | Evidence per dimension | Table with one-sentence findings |
| 4 | Decisions | Decision, needed by, owner, priority | Decision log | Table |
| 5 | Progress | Achievements and commitments | Work log, action register | Two bullet lists |
| 6 | Milestones | Milestone name, baseline date, forecast date, variance, status, owner | Schedule, milestone list | Table |
| 7 | Finance | Summary rows (budget, actual, EAC, variance) and notes | Cost records, budget | Table and notes |
| 8 | Exceptions | Risks, issues, assumptions, dependencies, changes with status and owner | RAID logs, change log | Table per type |
| 9 | Actions | Action, owner, due date, status | Action register | Table |
| 10 | Evidence notes | Data limitations, confidence notes, sources | Compilation notes | Bullet list |

---

## RAG Dimensions

| Dimension | What It Measures |
|-----------|-----------------|
| Scope | Changes, creep, acceptance status |
| Schedule | Milestone variance, critical path health, iteration velocity |
| Cost | Budget variance, EAC vs budget, burn rate |
| Quality | Defect trends, test pass rate, rework |
| Risk | Top risk exposure, response effectiveness, new risks |
| Resources | Staffing adequacy, skill gaps, turnover, availability |
